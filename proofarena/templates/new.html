Create and fund a bounty

Creating a bounty stores an off-chain manifest and its digest. Funding it requires a signed intent from your wallet; the API never signs for you.

What happens on submit

  1. POST /v1/challenges → off-chain manifest + metadata_hash.
  2. POST /v1/intents → a canonical message to sign.
  3. Your wallet signs it (fund_bounty); the signature is single-use.
  4. POST /v1/challenges/{id}/fund → escrow funded; state Open.
